Cleanup

A cleanup removes what updates and compose changes leave behind: stopped containers of a stack whose service is no longer in its compose file (running ones are kept), and untagged images no container uses that were pulled, tagged or replaced by an update more than {{.MinAgeLabel}} ago (STACKVAULT_CLEANUP_IMAGE_MIN_AGE). Volumes are never touched. It runs as a job on its own: it waits for running jobs, and other jobs wait for it.
