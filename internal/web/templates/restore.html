The stack is stopped and its directory is replaced by the snapshot's content. Changes made since the snapshot are lost from the live stack. The current directory is kept next to it ({{.Stack.Name}}.old-…) for a manual rollback.

Image versions

Pinning uses the image digests recorded in the snapshot's metadata.txt. Services built locally cannot be pinned and use compose.yml. If a pinned image can no longer be pulled, the restore is aborted and the current stack is started again. compose.yml is not changed: a later docker compose up uses the tags again.
