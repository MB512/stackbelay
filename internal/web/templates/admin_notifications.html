Notifications are off while the topic is empty. On the public ntfy.sh anyone who knows the topic can read it unless access control is set up: pick a name that is hard to guess, or use authentication.

Authentication

Only the fields of the chosen kind are used. An empty token or password field keeps the stored one. Credentials are stored encrypted.

Rolled back: an update or compose change failed and the stack runs the previous version again. Stack left down: a failed backup, update, compose change or restore left services down that ran before it; sent as urgent, which passes Do Not Disturb on Android. Cancelled jobs and updates that found nothing to change send no message. Jobs that finish within a minute of each other are sent as one message.

Stack monitor {{- range .Monitor}} {{- end}}

Every minute StackBelay reads the state of each stack and reports changes outside its jobs: a stack that becomes degraded (a service stopped, restarts or is unhealthy), stops without a Stop job, cannot be read, or whose directory is gone; and when it runs again after such a message. A state counts once it was seen three times in a row (two for "running again"), so restarts of a minute stay quiet. There is one message per change, no reminders; the summary lists stacks that stay degraded. Stacks that were already stopped when StackBelay first saw them, or were stopped by a Stop job, stay quiet. If Docker answers for no stack, one message names the host instead of every stack.

Summary

The summary covers the time since the previous one: what needs attention now (failed or stale backups, stacks without repository or backup schedule, degraded or stopped stacks, incomplete restores, available updates), then backups, downtime, updates, changes, restores, security events and the data added per repository. It is sent even when nothing happened, so a missing summary means StackBelay is not running. One missed while StackBelay was down is sent at its next start. Times are in the manager's time zone. With weekly backups, raise "stale after" above 7 days. The cron expression is used only with "custom".
