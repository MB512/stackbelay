Settings

{{- with .Form}}

Notifications are off while the topic is empty. On the public ntfy.sh anyone who knows the topic can read it unless access control is set up: pick a name that is hard to guess, or use authentication.

Authentication

Only the fields of the chosen kind are used. An empty token or password field keeps the stored one. Credentials are stored encrypted.
